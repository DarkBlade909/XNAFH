XNAFH
=========

Fork of XNALara Mesh import/export tool to import For Honor .ascii files.

Original addon by XNALara community.

Main Features:
- Imports For Honor .ascii meshes with armatures
- Automatically assigns textures to each material
- Uses a custom For Honor material shader to match the in-game look

### Known Issues

- The For Honor Shader nodegroup is still WIP and may not match perfectly to the in-game look
